## P0 — без этого инструмента нет

### AUD-01. Сборщик фактов `scripts/audit-collect.mjs`

Рецепт источника опирается на CLI, которых на машине нет: `curl -sI`
(`Аудит сайтов через OpenCode Генерация HTML-отчётов Qwen.html:148`) и
`openssl s_client` (`:151`). Проверено 16.11.2026: `Get-Command openssl` —
команды нет, `Get-Command whatweb` — нет, а в PowerShell `curl` подменён
алиасом `Invoke-WebRequest` и флаги curl не понимает.

Нужно: Node-скрипт без зависимостей (`fetch` + `node:tls` + `performance.now()`),
который по `sites.json` пишет `audit_data.json` с полями из
`docs/architecture.md` §3: `status`, `redirects`, `headers`, `tls`, `timing`,
`content`, `assets`, `seo`, `tech`, `findings`.

Приёмка: на живом адресе exit 0; несуществующий домен даёт `status: null` и
`error: "dns"`, а не падение всего прогона; повторный прогон даёт тот же набор
ключей; `node --check` чистый.

### AUD-02. Сигнатуры технологий вместо `whatweb`

`whatweb` — Ruby-гем, на Windows не ставится (`Аудит…Qwen.html:149`,
проверено `Get-Command whatweb`). Нужно: определение по четырём признакам —
`meta generator`, `wp-content`, `/bitrix/`, `_next/`, плюс `X-Powered-By`.
Отсутствие признака — пустой массив, а не «неизвестный сайт».

Приёмка: на трёх сайтах разных стеков (WordPress, Bitrix, Next.js) угадано не
меньше двух; ложное срабатывание фиксируется как `warn`, а не `ok`
(`docs/checks.md` §1).

### AUD-03. Шаблон отчёта и рендер `scripts/audit-render.mjs`

Источник предлагает просить модель «составить структурированный HTML-отчёт»
(`Аудит…Qwen.html:158-161`). Отклонено: пример отчёта — 14 453 байта, а лимит
`output` в профиле модели — 4096 токенов (`10-Приложения.txt:124`).

Нужно: `templates/audit-report.html` с плейсхолдерами `{{…}}` и рендер
подстановкой, без шаблонизатора. Разделы и статусы — по
`docs/report-format.md` §1–2.

Приёмка: два прогона на одном JSON дают побайтово одинаковый HTML; в готовом
файле нет `{{`; ноль внешних `http`-ссылок в `src`/`href`/`@import`; размер
≤ 150 КБ.

### AUD-04. Раздел «Выводы» моделью, ≤ 300 слов

Источник прямо предупреждает: не просить модель «проверить всё сразу и написать
отчёт» (`Аудит…Qwen.html:258`). Нужно: `scripts/audit-summary.mjs` читает
`audit_data.json` и отдаёт текст раздела «Выводы» — три пункта по приоритету,
каждый со ссылкой на `id` находки.

Приёмка: без модели отчёт валиден и содержит строку «модель не запускалась»;
с моделью — не больше 300 слов и ни одного числа, которого нет в JSON;
прогон на 3060 показывает `100% GPU` в `ollama ps`.

### AUD-05. `sites.json` и сравнение прогонов

Источник требует контроля динамики после любых изменений
(`Аудит…Qwen.html:247-250`). Нужно: вход `sites.json` (список адресов плюс
`allowlist`), прогон по всем адресам одним процессом и
`audit-render.mjs --compare <старый.json>`: дельта `ttfb_ms`, пропавшие и
появившиеся заголовки, изменение срока сертификата.

Приёмка: три адреса, один из них нерабочий — остальные собираются; сравнение
печатает дельту по каждому адресу; порядок в отчёте совпадает с `sites.json`.

## P1 — качество

### AUD-06. Внешние API: PageSpeed, Observatory, SSL Labs

Основание: `Аудит…Qwen.html:155-156`, `:206-208`, `:211-213`. Ограничения
источника: API видят только публичные адреса (`:257`), SSL Labs асинхронный и
с лимитом на IP.

Нужно: `scripts/audit-external.mjs`, ключи только из `.env`, `.env.example`
с именами переменных (`PAGESPEED_API_KEY`, `SSLLABS_EMAIL`).

Приёмка: с пустым `.env` — `external.*: null` и статус `unknown`, exit 0;
с ключом — данные в JSON; в логе не больше одного запроса в секунду.

### AUD-07. Вежливость: паузы, `User-Agent`, таймауты

Источник запрещает превращать аудит в нагрузку (`Аудит…Qwen.html:145`).
Нужно: 1 запрос в секунду на домен, `User-Agent: site-audit/<версия> (+контакт)`,
таймаут 10 с, максимум 5 редиректов, ответ 403/429 — `unknown` без обхода
(`docs/scope.md` §3).

Приёмка: в логе видны паузы и `User-Agent`; искусственный сайт с 429 даёт
`unknown` и не повторяет запрос.

### AUD-09. Команда `/audit` для OpenCode

Источник предлагает `commands/audit.md` (`Аудит…Qwen.html:137`). В каталоге
`.opencode/commands/` пока нет. Нужно: команда с `description` и
`$ARGUMENTS`, Windows-версия без `curl -sI` и `openssl`, с прямым запретом на
активное сканирование.

Приёмка: `/audit https://example.com` в OpenCode запускает сбор и рендер, не
предлагая Lighthouse, ZAP или k6; текст команды ссылается на `docs/checks.md`.

### AUD-13. Нормализовать переводы строк (`.gitattributes`)

проверено 16.11.2026: `git add` предупредил «LF will be replaced by CRLF the
next time Git touches it» для 23 файлов — в рабочей копии LF, при checkout
станет CRLF. Для документации и `.mjs` это шум в диффах. Нужно: `.gitattributes`
с `* text=auto eol=lf` и `*.bat text eol=crlf`, если появятся батники.

Приёмка: повторный `git add` без предупреждений; `git diff` после
переустановки на чистом клоне пуст; гейт `check:docs` зелёный.
