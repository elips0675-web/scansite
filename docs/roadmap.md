# Внешняя оценка: что принято, что отложено, что отклонено

Источник — `Аудит сайтов через OpenCode Генерация HTML-отчётов Qwen.html`
(предложение внешней модели) и комплект `D:\3060OllamaClineOpenCode-main 1`.
Здесь фиксируется решение, чтобы через месяц не спорить заново.

## 1. Принято

| Предложение | Где | Как реализуем |
|---|---|---|
| Слэш-команда `/audit` как точка входа | `:137` | `.opencode/commands/audit.md` (AUD-09) |
| Разбить на два шага: данные → отчёт | `:258` | стадии 1–2 в `docs/architecture.md` |
| Только пассивные проверки | `:145`, `:256` | `docs/scope.md` |
| Порядок: заголовки/TLS → скорость → SEO → API | `:246-250` | `docs/checks.md` §3 |
| Отдельная секция «Технологии» в отчёте | `:160` | `docs/report-format.md` §1 |
| Внешние API — по наличию ключа, а не обязательно | `:155-156` | `external.*: null` при отсутствии ключа |

### Принято частично (16.11.2026)

| Предложение | Где | Как реализуем |
|---|---|---|
| Chrome DevTools / Lighthouse | `:200-202` | через встроенный браузер OpenCode (`browser.lighthouse`), вручную; CLI по-прежнему не ставим |
| Сторонние скрипты и поддомены (вместо urlscan) | `:232-234` | `browser.network.list` по живому сайту: адрес не уходит третьей стороне |
| Скорость после JS (long tasks) | `:200-202` | `browser.trace`: Performance-категория Lighthouse недоступна, есть только accessibility/SEO/best practices |

## 2. Отложено (не отклонено)

| Предложение | Где | Почему отложено |
|---|---|---|
| Python-скрипт на `asyncio + aiohttp + Jinja2` | `:165-168` | второй рантайм; Node уже стоит, зависимостей ноль |
| W3C Validator | `:227-229` | сначала разбор `title/h1/canonical`; валидатор даёт шум по HTML5 |
| urlscan.io (сторонние скрипты и поддомены) | `:232-234` | нужен токен и раскрытие адреса третьей стороне; сторонние хосты считаем сами |
| UptimeRobot, Snyk в CI | `:248` | это мониторинг и зависимости, не аудит одного сайта |
| Screaming Frog (sitemap 2018 года) | `:249` | десктопное приложение, вне CLI; проверка `lastmod` у нас есть |
| axe DevTools (доступность) | `:249` | отдельный инструмент с браузером |

## 3. Отклонено

| Предложение | Где | Почему |
|---|---|---|
| Модель пишет HTML-отчёт с нуля | `:158-161` | 14 453 байта ≈ 5 тыс. токенов, лимит `output` 4096, риск битой вёрстки; шаблон детерминирован (`docs/local-model.md` §2) |
| `curl -sI` как основа проверки | `:148` | в PowerShell `curl` — алиас, флаги падают; Node даёт то же без процесса |
| `openssl s_client` | `:151` | в PATH отсутствует (проверено 16.11.2026); `node:tls` отдаёт протокол и срок |
| `whatweb` | `:149` | Ruby-гем, на Windows не ставится; сигнатуры в коде дают те же 3–4 технологии |
| OWASP ZAP, k6 | `:221-223` | активное сканирование и нагрузка: только письменное разрешение, не в этом инструменте |

## 4. Чего источник не учёл

| Факт | Проверено | Следствие |
|---|---|---|
| Машина на Windows, PowerShell | `curl` — алиас `Invoke-WebRequest` | все curl-команды переписать на `curl.exe` или Node |
| `openssl`, `whatweb` отсутствуют | `Get-Command` 16.11.2026 | два шага рецепта невыполнимы как написаны |
| Лимит вывода модели 4096 токенов | `10-Приложения.txt:124` | отчёт в один проход не влезает |
| 3060 на другой машине | `nvidia-smi` не найден | числа по скорости — из комплекта, не замер на месте |
| Внешние API не видят `localhost` | источник сам предупреждает (`:257`) | локальные сайты проверяются только кодом |
| В OpenCode есть браузер с Lighthouse, трейсом, сетью и консолью | каталог инструментов сессии, 16.11.2026 | часть «отложенного» закрывается без установки CLI, но только вручную и вне CI (AUD-14) |

## 5. Как пополнять

Новая внешняя оценка (Qwen, DeepSeek, Kimi) разбирается по тому же шаблону:
строка, цитата `file:line`, решение. Пункт без цитаты остаётся в
`docs/archive/`, а не здесь: «модель сказала» — не основание
(`docs/README.md` §2).
