# Архив документации

Здесь лежат заметки, которые перестали быть правдой: устаревшие профили
моделей, отменённые решения, разборы чужих оценок без цитат.

## Правила

- Файл в архиве не является правилом. Ссылаться на него можно, опираться — нет.
- Первая строка архивного файла — дата среза и ссылка на актуальный документ,
  например: «Срез 16.11.2026, актуально — `../architecture.md`».
- Удалять из архива ничего не нужно: он существует, чтобы не переписывать
  историю решений.
