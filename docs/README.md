# Карта документации

Один канонический набор документов на проект. Всё, что здесь не указано, —
черновик.

| Файл | Роль |
|---|---|
| `../AGENTS.md` | вход для агента: границы, бюджет, гейты, конец этапа |
| `../README.md` | обзор, этапы, обвязка машины, ограничения |
| `../project-context.md` | стек, решения, структура, точки интеграции |
| `../Что доделать.txt` | **только открытые** пункты бэклога (ID `AUD-NN`) |

## 2. Гигиена документации

- Новые правила не добавляются в `.txt`. `.txt` — только журнал и бэклог.
- Если файл не упомянут в `../AGENTS.md`, `../README.md` или здесь — он архив.
- Каждый пункт бэклога содержит `file:line` источника либо вывод команды
  (`проверено …`). Пункт без доказательства не принимается.
- Закрытый пункт удаляется из `Что доделать.txt` целиком и попадает одной
  записью в `Что сделано.txt`.
- Числа (размеры, версии, счётчики) берутся из кода или каталога и
  перепроверяются командой, а не перепечатываются из старых отчётов.
- Документы источника (Qwen-html, комплект `D:\3060OllamaClineOpenCode-main 1`,
  чужие проекты) остаются их документами. Ссылаться можно, копировать — нет:
  копия протухнет молча.
- Пустых заготовок в документах не бывает: гейт `npm.cmd run check:docs` роняет
  файл с незаполненным разделом.
