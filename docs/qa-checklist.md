# Приёмка этапов

Этап закрывается только при выполнении своего блока целиком. Числа
подставляются фактические, а не «ожидаемые».

## Этап 0 — документация (сделан 16.11.2026)

| Проверка | Как |
|---|---|
| Набор файлов на месте | `npm.cmd run check:docs` → exit 0 |
| Каждый документ из `docs/` есть в карте | тот же гейт |
| Каждый пункт бэклога с доказательством | тот же гейт (`file:line` или «проверено») |
| Журнал начинается со свежей записи | глазами: первая запись после шапки — `(Stage N — дата)` |
| Входной материал не считается истиной | в `AGENTS.md` §1 он помечен как предложение модели |

## Этап 1 — сбор данных (AUD-01, AUD-02)

| Проверка | Как |
|---|---|
| Скрипт не падает на живом адресе | `node scripts/audit-collect.mjs --sites sites.json` → exit 0 |
| Поля контракта присутствуют всегда | сверка `audit_data.json` с `docs/architecture.md` §3 |
| Один упавший адрес не валит прогон | фикстура: 1 валидный + 1 несуществующий домен → оба в JSON |
| Ключи одинаковы на двух прогонах | `node -e` сравнение набора ключей двух JSON |
| TLS без `openssl` | `tls.protocol` заполнен, `openssl` не вызывается |
| `--self-test` работает без сети | фикстура в `test/fixtures/`, exit 0 |
| Вежливость | в логе есть паузы и свой `User-Agent` |

## Этап 2 — отчёт (AUD-03, AUD-05)

| Проверка | Как |
|---|---|
| Рендер детерминирован | два прогона на одном JSON → побайтово одинаковый HTML |
| Нет незаполненных плейсхолдеров | поиск `{{` в готовом файле → 0 совпадений |
| Ноль внешних запросов | поиск `src="http`, `href="http`, `@import` → 0 |
| Размер в бюджете | `≤ 150 КБ` (`docs/report-format.md` §3) |
| `unknown` не зелёный | глазами: статус `unknown` серый `#6b7280` |
| Отчёт валиден без модели | раздел «Выводы» содержит «модель не запускалась» |
| Сравнение прогонов | `--compare` показывает дельту TTFB |

## Этап 3 — выводы моделью (AUD-04, сделано 16.11.2026)

| Проверка | Как |
|---|---|
| Не больше 300 слов | `conclusions.json` → `meta.words` ≤ 300; при превышении `truncated: true` |
| Каждая рекомендация ссылается на `id` находки | `meta.ids_cited` ≥ 3; при 0 скрипт не пишет файл (exit 1) |
| Нет чисел, которых нет в JSON | сверка каждого числа в тексте с `audit_data.json` глазами |
| Модель не обязательна | отчёт собирается и без `conclusions.json`, раздел заменяется строкой |
| Ollama не роняет прогон | остановленная Ollama → exit 1 и сообщение, отчёт не тронут |
| `100% GPU` на 3060 | `ollama ps` (на машине с картой; здесь CPU, проверено на `qwen2.5:3b`) |

## Этап 6 — перенос проверок из nlbopt и October CMS (сделан 16.11.2026)

| Проверка | Как |
|---|---|
| Почтовые политики разобраны | `import('./scripts/mail-policy.mjs')` → 11 случаев (`-all`, `~all`, `+all`, `?all`, `p=reject/quarantine/none`, нет `p`), 0 провалов |
| HTML-ветки не «на слово» | локальная фикстура `http://127.0.0.1:8099/` без интернета → 17 ожидаемых уровней совпали |
| Мягкая 404 | фикстура: путь-призрак отдаёт 200 с `title` главной → `soft_404: fail`; живой сайт с 404 → `ok` |
| Редирект HTTP→HTTPS | живой `ducasolutions.com` → `301` и `ok`; сайт по `http://` → `unknown`, а не `ok` |
| Директива `Sitemap` и тип карты | фикстура: `robots.txt` без `Sitemap:` → `warn`; `sitemap.xml` с `text/html` → `warn` |
| Бюджет запросов | `requests` = 5 на `ducasolutions.com`; потолок `docs/scope.md` §3 не превышен |
| Отчёт не раздулся | 15 КБ, 0 плейсхолдеров, 0 `<script>`/`<link>` |
| Контракт и отчёт совпадают | новые поля в `docs/architecture.md` §3, строки в `docs/checks.md` §1 |

## Этап 7 — PageSpeed вручную (сделан 16.11.2026)

| Проверка | Как |
|---|---|
| Файла нет — подраздела нет | убрать `audit-report/pagespeed.json` → рендер exit 0, в HTML нет строки «снят вручную» (упоминание PageSpeed в разделе 8 — это «что не проверялось», а не блок) |
| Битый JSON не роняет сборку | положить `{` в `pagespeed.json` → предупреждение в stderr, отчёт собран |
| Числа не смешаны с нашими | счётчики `ok/warn/fail/unknown` в шапке не изменились после появления файла |
| Цитата подписана | в блоке есть ссылка на отчёт, дата, устройство, версия Lighthouse и слово «цитата» |
| Бюджет | отчёт 20 КБ, 0 плейсхолдеров, 0 `<script>`/`<link>` |
| «Что делать» есть | списки «возможности» и «диагностика» непустые, каждая строка с экономией, если Google её дал |

## Этап 4 — внешние API (AUD-06)
| Проверка | Как |
|---|---|
| Без ключа не падаем | прогон с пустым `.env` → `external.*: null`, exit 0 |
| Ключи не в репозитории | `git check-ignore -v .env` |
| Лимиты соблюдены | в логе не больше 1 запроса в секунду на сервис |
| Публичные адреса | `localhost` даёт `unknown`, а не ошибку |
| SSL Labs дожидается `READY` | таймаут и число попыток в логе |

## Браузерный прогон (AUD-14)

| Проверка | Как |
|---|---|
| Lighthouse снят и записан | `external.browser.lighthouse` заполнен по трём категориям |
| Трейс не пустой | `external.browser.trace` содержит long tasks |
| Сеть сходится с HTML-разбором | число запросов из `browser.network.list` ≥ числа из `assets` |
| Ошибки JS перечислены | `browser.console`, каждая ошибка — строка в отчёте |
| Пометка «вне CI» на месте | поиск строки в готовом HTML |
| Нет ложного сравнения с PageSpeed | в отчёте написано, что эмуляции устройства нет |
| Гейты CI не зависят от браузера | `check:docs` зелёный без запущенного Chromium |

## Общий чек-лист перед словом «готово»

1. `npm.cmd run check:docs` — exit 0.
2. Запись в `Что сделано.txt` сверху, с `file:line` и «что не проверено».
3. Закрытый пункт удалён из `Что доделать.txt`.
4. Числа в документации совпадают с фактическим прогоном.
5. `git status` — только те файлы, что задуманы.
