# Приёмка этапов

Этап закрывается только при выполнении своего блока целиком. Числа
подставляются фактические, а не «ожидаемые».

## Этап 0 — документация (сделан 16.11.2026)

| Проверка | Как |
|---|---|
| Набор файлов на месте | `npm.cmd run check:docs` → exit 0 |
| Каждый документ из `docs/` есть в карте | тот же гейт |
| Каждый пункт бэклога с доказательством | тот же гейт (`file:line` или «проверено») |
| Журнал начинается со свежей записи | глазами: первая запись после шапки — `(Stage N — дата)` |
| Входной материал не считается истиной | в `AGENTS.md` §1 он помечен как предложение модели |

## Этап 1 — сбор данных (AUD-01, AUD-02)

| Проверка | Как |
|---|---|
| Скрипт не падает на живом адресе | `node scripts/audit-collect.mjs --sites sites.json` → exit 0 |
| Поля контракта присутствуют всегда | сверка `audit_data.json` с `docs/architecture.md` §3 |
| Один упавший адрес не валит прогон | фикстура: 1 валидный + 1 несуществующий домен → оба в JSON |
| Ключи одинаковы на двух прогонах | `node -e` сравнение набора ключей двух JSON |
| TLS без `openssl` | `tls.protocol` заполнен, `openssl` не вызывается |
| `--self-test` работает без сети | фикстура в `test/fixtures/`, exit 0 |
| Вежливость | в логе есть паузы и свой `User-Agent` |

## Этап 2 — отчёт (AUD-03, AUD-05)

| Проверка | Как |
|---|---|
| Рендер детерминирован | два прогона на одном JSON → побайтово одинаковый HTML |
| Нет незаполненных плейсхолдеров | поиск `{{` в готовом файле → 0 совпадений |
| Ноль внешних запросов | поиск `src="http`, `href="http`, `@import` → 0 |
| Размер в бюджете | `≤ 150 КБ` (`docs/report-format.md` §3) |
| `unknown` не зелёный | глазами: статус `unknown` серый `#6b7280` |
| Отчёт валиден без модели | раздел «Выводы» содержит «модель не запускалась» |
| Сравнение прогонов | `--compare` показывает дельту TTFB |

## Этап 3 — выводы моделью (AUD-04)

| Проверка | Как |
|---|---|
| Не больше 300 слов | подсчёт слов в разделе «Выводы» |
| Каждая рекомендация ссылается на `id` находки | глазами, выборочно 3 из 3 |
| Нет чисел, которых нет в JSON | сверка каждого числа в тексте с `audit_data.json` |
| Модель не обязательна | отчёт собирается и без неё, раздел заменяется строкой |
| `100% GPU` на 3060 | `ollama ps` (на машине с картой) |

## Этап 4 — внешние API (AUD-06)

| Проверка | Как |
|---|---|
| Без ключа не падаем | прогон с пустым `.env` → `external.*: null`, exit 0 |
| Ключи не в репозитории | `git check-ignore -v .env` |
| Лимиты соблюдены | в логе не больше 1 запроса в секунду на сервис |
| Публичные адреса | `localhost` даёт `unknown`, а не ошибку |
| SSL Labs дожидается `READY` | таймаут и число попыток в логе |

## Общий чек-лист перед словом «готово»

1. `npm.cmd run check:docs` — exit 0.
2. Запись в `Что сделано.txt` сверху, с `file:line` и «что не проверено».
3. Закрытый пункт удалён из `Что доделать.txt`.
4. Числа в документации совпадают с фактическим прогоном.
5. `git status` — только те файлы, что задуманы.
