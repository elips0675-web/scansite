# Папка `test` — вход для внешнего AI-аудита

Здесь лежит **самодостаточный срез** проекта для анализа в браузере (DeepSeek,
Qwen, Kimi и другие модели без доступа к диску).

| Файл | Что внутри |
|---|---|
| `Для анализа.txt` | стек, факты об окружении, структура, контракт `audit_data.json`, гейты, бэклог, ограничения, вопросы аудитору |

## Как пользоваться

1. Открыть `Для анализа.txt` и загрузить его в чат целиком.
2. Задать вопросы из раздела «Что смотреть аудитору» или свои.
3. Если модели нужен конкретный файл — назвать путь из раздела «Карта
   каталога»; этот файл передать отдельно.

## Что здесь **не** лежит

- Кода нет вообще: на Stage 0 в проекте только документация.
- `.env`, ключи API, дампы, пароли.
- `AGENTS.md`, `README.md`, `docs/*` — они остаются в корне и в `docs/`;
  в срезе дана выжимка и ссылки.
- Полный бэклог и журнал — `Что доделать.txt` и `Что сделано.txt` в корне.

## Когда обновлять

- После каждого закрытого этапа: меняются числа, статус выполнения, бэклог —
  править разделы 5–8 и дату среза в шапке.
- Перед отправкой на аудит проверять, что числа совпадают с фактическим
  прогоном `npm.cmd run check:docs`, а не перепечатаны из прошлой версии.
- Файл коммитится в репозиторий вместе с остальными документами.
